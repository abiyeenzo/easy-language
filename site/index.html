Programmer en francais,

Easy Language est un langage de programmation interprete en Python : mots-cles francais, blocs par indentation, listes, modules, et un debogueur pas-a-pas integre.

Fonctionnalites

Tout ce qu'il faut pour ecrire, tester et deboguer un script

Syntaxe francaise

soit, si, sinon, tantque, pour, fonction, retourne... aucune accolade, aucune virgule, aucun point-virgule.

Listes et modules

Tableaux avec [1 2 3], indexation, et importe "fichier.elg" comme module pour partager du code.

Debogueur integre

Points d'arret, execution pas-a-pas, inspection des variables en cours d'execution, en ligne de commande ou dans l'editeur.

Editeur avec coloration

Application de bureau (tkinter) : coloration syntaxique, execution en un clic, console de sortie et session de debogage interactive.

102 tests unitaires

Lexer, analyseur, interpreteur, modules et debogueur sont couverts par une suite de tests (stdlib, zero dependance).

Aucune dependance

L'interpreteur ne repose que sur la bibliotheque standard Python : meme comportement sous Windows, Linux et macOS.

Variables et affichage

soit declare une variable ; une reaffectation se fait sans soit. affiche accepte plusieurs valeurs separees par des espaces. demande lit une entree et convertit automatiquement en nombre si possible.

  • Types : nombres, texte, vrai / faux, rien
  • Operateurs : + - * / %, == != < > <= >=, et ou non
si age >= 18 alors:
    affiche "majeur"
sinon:
    affiche "mineur"

pour i de 10 jusqua 0 pas -2 alors:
    affiche i

Conditions et boucles

Blocs delimites par indentation apres :, comme en Python. si / sinon si / sinon, tantque, et pour ... de ... jusqua ... pas. arrete et continue controlent les boucles.

fonction fibonacci(n):
    si n <= 1 alors:
        retourne n
    retourne fibonacci(n - 1) + fibonacci(n - 2)

affiche fibonacci(10)

Fonctions

Les arguments multiples sont separes par des espaces, jamais des virgules : addition(1 2 3). La recursion et les portees locales fonctionnent normalement.

soit fruits = ["pomme" "banane"]
ajoute(fruits "kiwi")
affiche fruits[0]

pour chaque f dans fruits alors:
    affiche f

Listes / tableaux

Elements separes par des espaces entre crochets. Indexation en lecture et en ecriture, imbrication, et les natives ajoute, retire, contient, longueur.

importe "modules/mathutils.elg" comme math

affiche math.PI
affiche math.carre(5)

Modules

Chaque fichier .elg peut etre importe comme espace de noms. Le chemin est relatif au fichier qui importe ; un import circulaire est detecte proprement.

Easy Language

Un langage de programmation interprete en C, avec des mots-cles en francais. Pas de point-virgule, pas de virgule, pas d'accolade : les blocs sont indentes, comme en Python.

# exemple : exemples/bonjour.elg
soit nom = "monde"
affiche "Bonjour" nom

fonction carre(x):
    retourne x * x

pour i de 1 jusqua 5 alors:
    affiche "carre de" i "=" carre(i)

Fonctionnalites

  • Syntaxe francaise : soit, si, sinon, tantque, pour, fonction, retourne, et/ou/non...
  • Listes : [1 2 3], indexation, imbrication, natives ajoute/retire/contient
  • ~30x plus rapide qu'un interpreteur Python equivalent (coeur en C, points chauds en assembleur x86-64 inline)
  • Debogueur : points d'arret, pas-a-pas, inspection des variables (CLI et dans l'editeur)
  • Editeur graphique natif : coloration syntaxique (Win32/RichEdit), F5 pour lancer, F6 pour deboguer
  • Zero dependance : uniquement l'API Windows standard, aucun runtime a installer

Documentation

Variables et affichage 
soit x = 5
x = x + 1
affiche "x =" x
demande age "Ton age : "

soit declare une variable ; une reaffectation se fait sans soit. affiche accepte plusieurs valeurs separees par des espaces. demande convertit automatiquement en nombre quand c'est possible.

Conditions et boucles 
si age >= 18 alors:
    affiche "majeur"
sinon:
    affiche "mineur"

pour i de 10 jusqua 0 pas -2 alors:
    affiche i

Blocs indentes apres :. si / sinon si / sinon, tantque, pour ... de ... jusqua ... pas. arrete et continue pour controler les boucles.

Fonctions 
fonction fibonacci(n):
    si n <= 1 alors:
        retourne n
    retourne fibonacci(n - 1) + fibonacci(n - 2)

Arguments separes par des espaces, jamais des virgules : addition(1 2 3). Recursion et portees locales fonctionnent normalement.

Listes 
soit fruits = ["pomme" "banane"]
ajoute(fruits "kiwi")
affiche fruits[0]

pour chaque f dans fruits alors:
    affiche f

Elements separes par des espaces entre crochets. Indexation en lecture/ecriture, imbrication, natives ajoute, retire, contient, longueur.

Telecharger (Windows)

Interpreteur, debogueur et editeur ecrits en C, cross-compiles automatiquement par la CI GitHub Actions a chaque release. Aucune dependance a installer. Les trois fichiers doivent rester dans le meme dossier.

  • easy_editeur.exe : editeur graphique (coloration syntaxique, F5 lancer, F6 deboguer). Point de depart recommande.
  • easy_language.exe : interpreteur, en ligne de commande.
  • easy_debogueur.exe : debogueur pas-a-pas, en ligne de commande.
  • EasyLanguage-windows.zip : les trois + les exemples, en un seul telechargement.
